# Woodshed

A 12-week practice curriculum for R&B, neo-soul, and modern gospel keys/piano. Tick off tasks, voicings, progressions, and licks as they stick; track keys, tempos, and skill scores. Includes a Nashville number-system lab for transposing progressions across keys and hearing them with a backing band. All progress saves in the browser (no backend).

Entry point: `index.html`.

## What's inside

- `index.html` — main app
- `support.js` — supporting script
- `screenshots/` — reference images

## Hosting

Deploy as-is to any static host (GitHub Pages, Netlify, Vercel, etc). `index.html` is the root entry point.
